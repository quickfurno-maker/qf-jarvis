## 4. What this index deliberately does not do

It does not adopt an event, name a protocol, propose a schema, choose an ADR-0135 option, treat generic
persistence capacity as persistence of a specific fact, treat a status vocabulary as a business
operation, or certify live database state. Every ambiguity is left as `AMBIGUOUS_REQUIRES_D2` in the
main report.
